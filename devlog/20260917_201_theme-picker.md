# 화면에서 테마를 고른다 — 시스템 · 밝게 · 어둡게

## 지금까지는 OS 가 정했다

색이 전부 `:root` 토큰이었지만 밝은 값은 `@media (prefers-color-scheme: light)`
안에 있었다 — OS·브라우저 설정을 그대로 따라가고 화면에서 고를 길이 없었다.
어두운 방의 밝은 화면, 밝은 방의 어두운 화면을 사용자가 못 바꿨다.

## 결정한 것

### CSS 는 속성만 본다 — 미디어 쿼리를 걷었다

밝은 토큰을 `:root[data-theme="light"]` 로 옮기고 미디어 쿼리를 없앴다. 어느
쪽인지는 **`<head>` 의 스크립트**가 정한다: `localStorage` 의 `diaruga.theme`
(`light`·`dark`)이 있으면 그것, 없으면 `matchMedia('(prefers-color-scheme:
light)')`. 시스템을 따를 때는 OS 가 바뀌면 `change` 로 같이 바뀐다.

미디어 쿼리를 남겨 두고 속성으로 덮는 길(`:root:not([data-theme="dark"])`)도
있었지만 밝은 값을 두 번 적게 된다. 값이 한 벌만 있어야 다음에 토큰을 더할 때
한쪽만 채우는 실수가 없다(`--sea-*` 를 더한 200 이 바로 그런 자리였다).

### 스크립트가 `<style>` 보다 앞이다

뒤에 두면 첫 그림이 어두운 색으로 한 번 찍혔다가 바뀐다 — 밝게 골라 둔 사람이
페이지마다 깜빡임을 본다. 시험(`test_theme.py`)이 그 순서를 본다.

### 단추 하나가 셋을 돈다

머리줄 톱니 왼쪽, 도감 단추 앞. 누를 때마다 **시스템 ◐ → 밝게 ☀ → 어둡게 ☾**
이고 툴팁이 지금 상태를 적는다. 세 갈래를 셀렉트로 두는 것보다 한 번 눌러 보면
아는 쪽이 이 머리줄에 맞다 — 늘 보는 자리라 자리를 안 차지해야 한다.
"시스템" 이 따로 있는 이유는 지운 뒤 OS 를 다시 따르는 길이 있어야 해서다 —
밝게/어둡게만 있으면 한 번 고른 뒤로는 영영 OS 와 갈린다.

**오프라인 검토기에도 보인다.** `base.html` 을 그대로 쓰므로 저절로 따라간다 —
현장에서 밝은 곳·어두운 곳이 갈리니 오히려 거기서 더 쓸 일이다. `file://` 에서
`localStorage` 가 막히면 그 화면에서만 바뀐다(try 로 감쌌다).

`color-scheme` 도 같이 준다 — 스크롤바·셀렉트 같은 브라우저 기본 그림이 고른
테마를 따른다. 예전에는 OS 대로였으니 OS 와 갈라 고른 사람에게만 달라진다.
