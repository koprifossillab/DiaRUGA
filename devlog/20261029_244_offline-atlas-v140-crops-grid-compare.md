## 왜

사용자 요청: "오프라인 도감 뷰어를 현재 뷰어 체계 기반으로 새로 구워 주자".

v1.3.0 이후 서버 도감 화면에 셋이 생겼는데 꾸러미에는 하나도 없었다.

- **그림 크롭** — 논문 넷(239) · 한국 도감 512(240) · Schmidt 963(241). 크롭이 있는 종이 313 → 1,650 이 됐다
- **검색 결과의 바둑판 보기**(238) — 칸마다 그림 하나
- **종 2~5개 비교**(238) — 한 표에 나란히

바둑판과 비교는 "**크롭이 먼저**" 라는 규칙(`data._row_figure`) 위에 서 있다. 그래서 크롭 없이
두 화면만 옮기면 같은 종이 서버에서는 그 그림 하나로, 꾸러미에서는 도판 한 쪽 전체로 뜬다 —
두 화면이 다른 말을 한다(196 의 원칙).

## 버린 것 — 09-03 의 "크롭은 안 싣는다"

09-03 에 사용자가 크롭을 빼기로 했다(그때 이유: 쪽 이미지가 다 들어가니 도판에서 보인다).
**그때는 논문 크롭 440장(21 MB)뿐이었고 크롭을 쓰는 화면도 없었다.** 지금은 2,584장이고
두 화면이 크롭을 먼저 쓴다. 사용자의 이번 요청("현재 뷰어 체계 기반")을 그 결정을 거두는
것으로 읽었고, 크기가 얼마나 느는지 말한 뒤 진행했다.

## 한 것

**굽는 쪽** (`tools/build_offline_atlas.py`)

- 색인의 `crop_image`(`atlas/<도감>/crops/<이름>.png`)를 모아 `crops/<도감>/crops/<이름>.jpg` 로
  굽는다. 경로는 앞머리 `atlas/` → `crops/`, 확장자만 바꾼다 — 이름을 새로 짓지 않는다(`rel_crop`)
- **쪽처럼 디스크에 있는 것만 싣는다.** 색인이 짚는데 `--crops-root`(기본 `/data3/DiaRUGA`)에
  없는 크롭은 세어서 말하고 경로를 빈 채로 둔다 — 안 열리는 그림을 내지 않는다. 이번에는 0장이었다
- **JPEG 품질 85 · 해상도 그대로.** 쪽과 같은 까닭이다(세선을 볼 자리). 원본은 전부 회색조(`L`)이고,
  투명이 있으면 흰 종이에 얹도록 해 두었다
- 자리마다 `crop_rel` 을 싣는다 — 뷰어 `_placement_dict` 의 같은 이름 칸이다
- 글자만 담는 단일 HTML 에서는 `crop_rel` 을 비운다(그림이 없는 파일이다)
- `MANIFEST.json` 에 `crops` · `missing_crops`, `meta.crop_count`, README·안내 화면에 크롭 수
- `--limit` 이 크롭도 도감마다 N장으로 줄인다(눌러 볼 때)

**화면** (`tools/offline_assets/app.js`·`app.css`)

뷰어 238 을 옮겼다 — 같은 규칙, 같은 이름(`localStorage` 키 `diaruga.atlas.view`·`diaruga.atlas.compare`).

- 색인 결과마다 **그림 보기** 칩. 마우스를 올리면 크롭만 미리 보이고, 누르면 도판 쪽으로 간다
- **목록 · 바둑판** 단추(앞 판 줄에만 — 뒤 줄에도 두면 같은 id 가 둘이 된다). 두 보기를 다 그려 두고
  감싼 칸의 클래스 하나(`av-list`·`av-grid`)로 한쪽을 감춘다 — `[hidden]` 은 `.agrid` 의
  `display: grid` 에 진다(CLAUDE.md)
- 칸의 그림은 `rowFigure` — **크롭이 먼저, 없으면 도판 쪽 축소본, 주석이 달린 자리는 안 띄운다**
  (`data._row_figure` 의 두 벌이다). 그림이 없으면 「그림 없음」, 안 열리면 「이 꾸러미에 없습니다」
- **비교에 담기** — 다섯이 차면 담지 않은 칸만 잠근다. 담기 직전에 저장된 목록을 다시 읽어 다른
  탭에서 담은 것을 덮지 않는다. 띠는 머리줄 높이를 재서 그 밑에 붙는다(`--headh`)
- **비교** 화면 `#/compare?e=<도감>:<표제어>&e=…` — 해시의 같은 이름 값을 다 받도록 `parseHash` 가
  `multi` 를 낸다. 열쇠·차례·못 찾은 열쇠(`missing`)·다섯 넘는 것(`over`)·「한 종이라도 값이 있는
  줄만」·빈 칸은 「—」 이 전부 `atlas_compare` 와 같다. 보고 있는 비교를 담은 목록에 다시 적는다.
  「도감」 은 마지막으로 본 검색 결과로 돌아간다
