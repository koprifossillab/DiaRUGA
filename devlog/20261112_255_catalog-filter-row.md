# 255 — 카탈로그의 거르개 줄을 다시 짠다

2026-11-12 · sclee · `work/20261112-sclee` · 사용자 요청("굉장히 난잡하다 — 대부분은
4차 검출 이전에 데이터 정제를 위해 둔 것")

## 무엇이 문제였나

`형태` 한 줄에 칩이 스물일곱이었다 — 분류 열넷(이 슬라이드에 없는 속까지) ·
동정 상태 셋 · 정제용 일곱 · 파편 체크박스 · 지운 것 · 이 쪽 전부 고르기.
뜻이 다른 것이 같은 모양으로 한 줄에 있었고, **전부 `cls` 한 칸을 나눠 썼다** —
"봉상" 을 누른 채 "덜 된 것" 을 누르면 봉상이 풀렸다.

## 어떻게 갈랐나

| 줄 | 무엇 | 달라진 것 |
|---|---|---|
| **유형** | 완형 분류 · 묶음(원통상) | **이 슬라이드에 없는 유형은 칩을 안 놓는다.** 골라 둔 것은 0 이어도 놓는다(풀 자리) |
| **파편** | 「함께 보기」 + 파편 분류 | 체크박스를 칩으로. 기본으로 감추는 것이라 줄을 따로 뒀다 |
| **동정** | 덜 된 것 · 동정 완료 · 코멘트 있음 | **유형과 함께 걸린다** — 새 칸 `st` |
| **정제용 거르개** | 수동 복구 · 유형을 사람이 지정 · 유형 미지정 넷 · 합성본에 없음 | **접어 둔다**(`<details>`). 고르면 펴진 채로 뜬다 |

- **칩마다 수를 적는다.** 수는 **눌렀을 때 놓일 카드의 수**다 — 다른 줄에 건 것과
  검색을 건 채로 센다. 칩의 수와 카드를 **같은 식**(`cls_ok`·`st_ok`·`q_ok`)에서
  내어 "12" 를 눌렀는데 9장이 놓이는 일이 없게 했다
- **켜진 칩을 다시 누르면 풀린다.** 뭔가 걸려 있으면 「거르개 모두 풀기」 가 뜬다
- 「지운 것 보기」 와 「이 쪽 전부 고르기」 는 거르개가 아니라서(보기를 바꾸는 것 ·
  일) 오른쪽에 따로 뒀다
- **주소는 뷰가 만든다**(`href()`). 템플릿이 칩마다 질의 문자열을 손으로 이어
  붙이던 자리가 일곱이었다

## 안 바꾼 것

- **옛 주소가 그대로 돈다.** `?cls=unnamed`·`named`·`noted` 는 `st` 로 읽는다.
  정제용의 `?cls=untyped_rod` 등은 그대로다
- 파편을 기본으로 감추는 것 · 파편 유형을 집으면 그것만 내는 것 · 지운 것과
  「합성본에 없음」 이 파편까지 다 내는 것 — 규칙은 그대로이고 자리만 옮겼다
- 진행도(`n_all`·`n_named`·`n_frag`)의 뜻. 「함께 보기」 옆의 수는 따로 센다
  (`f_frag_n` — 지금 건 거르개 안에서 감춰진 파편)
- 「사람 지정」 은 이름만 「유형을 사람이 지정」 으로 풀었다

## 당한 것

- **`{% class_list as classes %}` 가 칩 줄 안에 있었다.** 줄을 통째로 갈면서
  사라져 **카드의 유형 셀렉트가 빈 채로 그려졌다** — 예외도 경고도 없다. 잡은
  것은 `test_카탈로그_유형_셀렉트에_뜬다` 인데, 그 시험은 그동안 **칩의 글자로
  통과하고 있었다**(카드가 없는 픽스처였다). 카드를 세우고 `<option>` 을 보게
  고쳤다
- `urlencode` 가 `group:cylinder` 의 `:` 을 `%3A` 로 바꾼다 — `safe=":"`

## 정하지 않은 것 (사용자가 내일 본다)

- 줄의 이름(유형·파편·동정·정제용 거르개)과 칩의 말
- 0 인 유형을 감추는 것이 맞는가 — 감추면 "이 슬라이드에 없다" 가 안 보인다
- 정제용에서 아예 걷어도 되는 것이 있는가(4차 뒤로 수가 전부 0 인 것들)
- 크롭 화면(`crops.html`)의 칩 줄은 안 건드렸다
