## 1. 8단계의 화면 일곱이 축약 표기였다 — 그대로 치면 404 다

릴리스 흐름 8절은 *"일곱을 연다 — `/crops/` · `/detections/` · `/catalog/` ·
`/g/1/` · …"* 라고 적혀 있다. 그대로 열었더니 **넷이 404** 였다.

고장이 아니라 **URL 을 잘못 짚은 것이다.** 실제 경로는 슬라이드 슬러그를
받는다 (`web/viewer/urls.py`).

| 문서 | 실제 |
|---|---|
| `/crops/` | `/d/<슬러그>/crops/` |
| `/detections/` | `/d/<슬러그>/detections/` |
| `/catalog/` | `/d/<슬러그>/catalog/` |
| `/g/1/` | `/d/<슬러그>/g/<gid>/` |

`/thresholds/` · `/system-settings/` 만 슬러그 없이 서는 자리라 200 이었고,
그래서 **"셋은 되고 넷은 안 된다" 처럼 보였다.**

**이 축약이 위험한 이유는 8절이 있는 이유와 정확히 반대이기 때문이다.** 8절은
086 에서 왔다 — `/crops/`·`/detections/` 가 **v0.8.0 이후 내내 500** 이었는데
`smoke.sh` 가 링크를 안 만들어 통과시켰다. 그 구멍을 손으로 메우라는 절인데,
**404 를 받고 "원래 그런 자리인가" 하고 넘어가면 500 을 못 본다.** 404 와 500 을
가르는 것은 그 자리에서 URL 을 다시 짚어 보는 사람뿐이다.

## 2. 한 슬라이드가 아니라 12개 전부를 열었다

086 의 교훈은 "URL 을 덮는 것과 갈래를 덮는 것은 다르다" 였다 — 시험 셋이
`/crops/`·`/detections/` 를 열고 있었는데 **세운 자료가 전부 합성본 시야라**
프레임 갈래를 한 번도 안 지났다.

**어느 갈래로 가는지는 슬라이드마다 다르다.** 한 슬라이드로 다섯 화면을 열면
URL 다섯을 덮은 것이지 갈래를 덮은 것이 아니다. 그래서 목록에서 슬러그를
긁어 전수로 돌렸다.

```bash
curl -s $B/ | grep -o 'href="[^"]*/d/[^"]*/"' | sed 's#.*/d/##; s#/"##' | sort -u
for s in $(cat slides); do
  for p in detections crops catalog thresholds; do
    curl -s -o /dev/null -w '%{http_code}' "$B/d/$s/$p/"
  done
done
```

12 × 4 = 48 개 + 검토 화면 12 개 = **60 개 전부 200.**

## 3. 200 은 "떴다" 일 뿐이라 앵커를 셌다

이번 판의 알맹이는 검토 화면 오른쪽 칸이다(183). 그 칸이 **안 그려져도 200 은
나온다** — 템플릿이 조건 안에서 통째로 빠지면 예외도 경고도 없다.

`a98acc0` 이 새로 넣은 표식을 뽑아 그것이 응답 안에 있는지 셌다.

```
id="catpane-{{ uid }}" · id="catspecies-{{ uid }}" · id="catgp-{{ uid }}"
```

12 시야 전부에서 셋이 다 나왔고 본문도 300~580 KB 였다. **`grep -c` 가 0 이
아닌 것까지 봐야 "칸이 놓였다" 고 말할 수 있다.**

## 4. CHANGELOG 날짜가 이틀 어긋나 있었다

항목이 `09-04` 로 적혀 있었는데 실제로 나간 날은 `09-06` 이다.

어긋난 것이 실수가 아니라 **절차의 모양 때문이다.** 3단계가 *"문서를 먼저
맞춘다 — 태그가 그 커밋을 가리킨다"* 이므로 CHANGELOG 를 쓰는 시점에 날짜는
**예정일**일 수밖에 없다. 그날 태그를 밀면 맞고, 미뤄지면 어긋난다.

지난 판들은 전부 같은 날 나가서(`v0.22.1`·`v0.22.4`·`v0.22.5` 모두 CHANGELOG
날짜 = 배포일) 이 갈래가 안 드러났다. **12단계에서 날짜를 배포일로 맞춘다** —
`v0.9.3` 이 뭐였는지 묻는 사람에게 필요한 것은 초안을 쓴 날이 아니다.
