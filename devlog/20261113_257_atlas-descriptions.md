# 도감의 기재문을 뽑아 도감 화면에 얹는다 (257)

2026-11-13. 사용자가 **"도감에서 description 은 일절 추출 안 했어?"** 라고 물었고,
안 했다. 색인은 "이름 → 도판·그림 자리" 를 잡으려고 짠 것이라 한국 도감에서
생태·분포만 옮겼고 형태 기재는 그때그때 쪽을 렌더해 읽는 것으로 두었다
(`Diadiction/README.md`). 이번에 전부 뽑아 도감 화면에 얹는다.

## 1. 원본이 둘이다 — 둘 다 남긴다

| | 덮는 것 | 성한 것 | 깨진 것 |
|---|---|---|---|
| PDF 텍스트 레이어 | 한국 도감 #169–480 | 한글 | `μ`(11개뿐) · 괄호 속 한자(빈 괄호 660곳) |
| OCR 서버 ([P21](20260828_P21_ocr-server.md)) | 전부 | `μ`(568개) · 한자 | 학명 철자 · 한글 일부(`주연(周緣)` → `주변(周緣)`) · 라벨 글자 |

**어느 쪽도 정본으로 못 쓴다.** 그래서 섞지 않고 둘을 나란히 낸다 — 섞는
규칙이 틀리면 원문에 없는 문장이 생긴다. 화면이 "기계가 읽은 원문 · 쪽과
대조할 것" 이라고 말한다.

## 2. OCR — 가진 PDF 를 전부 넣었다

`tools/ocr_pdf.py` 로 도감 여섯(한국 발췌본 · Schmidt Band1–4 · 동남극
도판집)과 논문 스물넷을 올렸다 — 텍스트 레이어가 있는 논문도 넣었다(버리는
것 없이 두 원본을 다 갖는다). 서버는 `1ocr` 모드(백엔드 하나 · 동시 6쪽)였고
쪽당 약 5초다. 산출은 `Diadiction/ocr/<PDF 이름>/` 에 쪽마다 걷은 것과
서버 원본(`.raw.html`)이 함께 있다.

- 도구가 **올리자마자 `job_id` 를 적고**, 끝난 PDF 는 건너뛰고, 끊긴 job 은
  이어 받는다. 몇 시간짜리를 tmux 에 띄우려면 필요했다
- **한국 도감 원본 전체(570쪽)는 안 넣었다** — 발췌본 270쪽과 겹치고 나머지는
  다른 조류다. 그래서 #680 의 본문이 없다(발췌본이 p.369 에서 잘린다)

## 3. 가르기 — 읽은 글자가 전부 어딘가에 놓인다

`tools/parse_descriptions.py` 가 한국 도감 본문을 항목별로 가른다. 표제 줄과
`생태` 사이가 기재문이고, 항목 사이의 과·목 기재와 검색표, 첫 항목 앞의
범례, 도판 목록 쪽, 쪽 머리까지 **각자 자리에 남긴다.** 끝에 들어온 글자 수와
놓인 글자 수를 대조해 어긋나면 멈춘다.

| | 텍스트 레이어 | OCR |
|---|---|---|
| 표제 | 312 (#169–480) | 510 |
| 못 찾은 번호 | #481–680 | #632 · #680 |
| 기재문 길이(가운데 · 최대) | 164 · 580자 | 171 · 616자 |

- **#632** 는 OCR 이 표제의 번호와 `pl. 68` 을 빠뜨렸다. 본문은 #631 뒤에
  붙어 있다. 번호를 지어 붙이지 않았다
- **OCR 의 `생태`·`분포` 라벨은 자주 깨진다**(`〔문포]`·`궤태:`). 생태 223칸 ·
  분포 99칸은 순서로 정했다 — 그 칸의 이름은 추정이다. 화면에는 색인이 이미
  든 생태·분포를 그대로 쓰고 OCR 것은 안 싣는다
- **표제 이름이 색인과 다른 것**이 텍스트 레이어 기준 43건이다. 색인이 이름을
  자른 자리(`var. impres`)와 `Syn.` 줄을 빠뜨린 자리가 있다. 색인은 안 고쳤다
  (`outputs/descriptions/korean_name_diffs.md`)

`tools/merge_descriptions.py` 가 두 원본을 항목마다 나란히 놓는다
(`korean_merged.json` · 사람이 읽는 `korean_descriptions.md`).

## 4. 반입 — 색인 JSON 에 적지 않는다

기재문은 `atlas/descriptions/<도감>.json` 으로 따로 실려 가고
(`tools/build_atlas_descriptions.py`), `ops/import_atlas.py` 가 항목의 `extra`
에 `description`(OCR)·`description_text`(텍스트 레이어)를 얹는다.

- **`atlas/korean.json` 에 적으면 사라진다** — `parse_atlas.py` 가 md 에서 다시
  뽑는 사본이다
- **`seq` 와 표제어가 둘 다 맞아야 얹는다.** 색인을 다시 뽑아 `seq` 가 밀리면
  기재문이 옆 종에 붙는데 예외는 안 난다 — 어긋나면 반입을 되돌린다
- **칸을 새로 만들지 않았다**(마이그레이션 없음). `extra` 가 "도감마다 다른 것"
  의 자리다(P15 4.1)

화면은 도감 목록의 항목마다 접힌 「기재」 칸, 비교 화면에 「기재」 줄이다.

## 5. 일을 나눈 방식

OCR 은 tmux 세션 셋으로 올렸고, 가르기는 **Sonnet 으로 고정한 Claude 를 tmux
세션 셋**(한국 · Schmidt · 논문)으로 띄웠다 — 지시문은
`~/notes/DiaRUGA/desc-jobs/` 에 있다. 쓰는 자리를 `tools/` 의 새 파일과
`Diadiction/outputs/` 로 묶고 커밋·docker·`rm` 을 막았다. 결과는 이 세션이
검토해 커밋한다.
