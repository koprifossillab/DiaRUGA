# 235 — 첫 화면에 로고가 그려지는 GIF 를 띄운다 (탭마다 한 번)

2026-10-24 · `work/20261024-sclee-ui` 에서 짜고 `work/20261024-sclee-splash` 로 옮겨 냈다

## 무엇을

사용자가 "과거에 대기화면 gif 따위를 반입했을 것" 이라며 찾았다. 213
(`work/20260923-sclee`, 2026-09-23)의 **잠금 화면**에 딸려 들어온 로고 GIF 였다.
그 브랜치는 `main` 에 병합된 적이 없고, 병합했더라도 `DIARUGA_GATE_CODE` 가
비면 꺼지는 설계라 화면에 나온 적이 없다.

사용자 답: **"그냥 항상 나오는 것으로."** 셋을 놓고 물었고(코드 없이 탭마다 ·
코드 없이 페이지마다 · 잠금 화면 그대로 켜기) **코드 없이, 탭을 새로 열어
들어올 때마다**를 골랐다.

## 한 것

- `web/viewer/assets/splash/` — 213 의 `logo.gif`(842 KB)·`logo.png`·`logo.json`
  을 바이트 그대로 가져왔다. 굽는 도구도 `tools/splash_logo.py` 로 가져와
  출력 자리만 바꿨다(GIF 끝 장면이 원본 PNG 와 같게 굽는 방법은 213 에 있다)
- `views.splash_asset` · `/splash/<이름>` — 이름 둘만 받는다. 정적 파일 길이
  없는 배포라 뷰가 낸다(하루 캐시)
- `base.html` — `<head>` 에서 `sessionStorage` 에 본 기록이 없으면
  `<html class="splashing">`, `<body>` 맨 앞 `splash` 블록의 덮개가 GIF 를 받아
  돌리고, 끝 장면(`build_ms` + 0.1초)에서 원본 PNG 로 바꾸고, 0.8초 뒤 걷는다.
  누르거나 키를 치면 바로 걷는다. 움직임 줄이기 설정이면 PNG 만 0.7초
- 잠금(코드·쿠키·미들웨어)은 **안 가져왔다**

## 왜 그렇게 했나

- **탭마다 한 번(`sessionStorage`).** 페이지마다 띄우면 검토 화면을 오갈 때마다
  2.4초를 붙든다. 같은 탭 안에서는 다시 안 뜬다. **띄운 순간 적는다** — 다 보기
  전에 다른 페이지로 가도 또 뜨지 않게
- **저장소가 막힌 브라우저에서는 아예 안 띄운다.** 못 적으면 페이지마다 뜬다
- **`<head>` 에서 클래스를 붙인다.** 본문이 한 번 그려진 뒤 덮으면 깜빡인다
- **바탕색 `#0f1115` 를 박았다.** GIF 가 반투명을 못 담아 그 색 위에 구워져
  있다 — 테마 토큰을 쓰면 밝은 테마에서 GIF 둘레에 네모가 비친다(213 과 같은
  이유). 둘을 함께 바꾼다
- **GIF 가 4초 안에 안 오면 기다리지 않고 걷는다** — 느린 망에서 빈 검은 화면에
  갇히지 않게
- **오프라인 꾸러미(`offline_review`·`offline_catalog`)는 블록을 비운다.** 서버
  없이 여는 파일이라 로고 주소가 없다

## 시험

- `test_splash.py` — 로고 둘이 나가고 다른 이름은 404, `build_ms` 를 읽는가,
  목록에 덮개가 있는가
- `browser/test_splash.py` — 새 탭에서 뜨고, 걷히고, 끝에 PNG 로 바뀌었고,
  같은 탭의 다음 페이지에서는 안 뜨는가 · 누르면 바로 걷히는가
- **다른 브라우저 시험은 본 것으로 치고 연다**(`BrowserTestCase.skip_splash`) —
  덮개가 2.4초 동안 클릭을 막아 모든 시험이 그만큼 기다리게 된다
- **`test_mobile.py` 는 맥락을 새로 만들어 위 건너뛰기가 빠졌다** — 덮개가 탭·길게
  누르기를 가려 둘이 실패했다. 같은 줄을 그쪽에도 건다(옮겨 낸 세션이 전체 시험에서
  잡았다)
