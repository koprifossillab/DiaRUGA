# 213 · 오프라인 도감 v1.3.0 — 생층서 기준면 줄을 싣는다

2026-09-27 · P28 §5 · 앞 판은 v1.2.0(196, 09-15)

## 왜

v1.2.0 이후 원본이 움직여 꾸러미가 조용히 낡아 있었다 — 남극 논문 도감 셋
(207·209)이 없고, 권역 누락(3deb52e)과 캡션 속명 약자(211)가 고치기 전이고,
이명 판정이 2,031 → 2,126 으로 늘었고, **기준면(P28)은 아예 안 실려 있었다.**
서버 카드에는 「기준면」 줄이 뜨는데 꾸러미에는 안 떠 두 화면이 다른 말을 했다
(196 의 원칙).

## 한 것

- `build_offline_atlas.py` 가 `atlas/biodatum/datums.json` → `data/biodatum.js`
  (`DIA_BD = {card, genus}`)로 싣는다. `MANIFEST.json` 에 `biodatum_sha256`.
- 카드 줄은 뷰어 `data._biodatums_by_binomial` 의 규칙을 그대로 옮겼다 —
  전범위(`total`) 제외 · 원문과 값이 같은 재인용 제외(`_dedupe_via`) · 이름 →
  기준면 → 연령 차례. 속 목록의 `· 기준면 N` 은 `biodatum_counts_by_genus`
  처럼 거르지 않은 전부를 센다.
- **연령은 문자열로 싣는다.** 템플릿은 `13.0` 으로, JS 는 `13` 으로 찍는다.
- 도움말·README 에 기준면 행 수를 적었다.
