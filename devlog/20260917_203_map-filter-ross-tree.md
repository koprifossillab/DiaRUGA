# 지도 모드 — 보일 슬라이드 고르기 · 로스해 확대에서는 나무도 틀 안만

**작성일** 2026-09-17 · 사용자 "지도 모드로 볼 때 체크박스 나오는 작은 화면을
펴서 원치 않는 슬라이드를 감췄으면 좋겠고, 로스해 확대 상태면 오른쪽에
로스해 시료만 떴으면 좋겠어"

---

## 둘 다 오른쪽 나무의 일이다

지도 모드의 오른쪽은 지역 → 코어 → 슬라이드 나무다. 슬라이드가 열여덟이
되면서 (1) 보고 싶지 않은 것을 잠깐 치울 길이 없었고, (2) 로스해 확대로
갈아타도 나무는 남극반도·아문젠해까지 그대로여서 지도와 나무가 다른 것을
말했다.

## 결정한 것

### 감추는 것은 이 브라우저에서만 — 서버에 안 쓴다

사용자에게 물었다(2026-09-17). 슬라이드 속성의 「숨김」(`hide_in_list`)을
체크박스로 한꺼번에 켜는 길도 있었지만 그것은 **모든 사람의 목록·합계에
걸리는 자료의 성질**이고, 여기 필요한 것은 지도를 보는 사람 하나의 보기
상태다. `localStorage`(`diaruga.maphide`)에 slug 목록으로 남고 다시 열어도
남는다. 「모두 보이기」 가 비운다.

### 고르는 판은 나무와 따로다

`<details>` 로 접힌 「보일 슬라이드 고르기」 — 같은 지역·코어 나열에
체크박스. 나무 안에 체크박스를 섞는 길은 버렸다: 고르는 중과 보는 중이 한
화면에 겹쳐, 끈 것이 보이는지 안 보이는지가 흔들린다. 나열을 한 번 더 적는
값이 그보다 싸다.

### 숫자가 따라온다

끈 슬라이드의 줄이 사라지고, 코어의 「슬라이드 N장」과 마커의 「시야 N」을
남은 줄로 다시 센다(`data-vp`). 코어가 다 꺼지면 코어가, 지역이 다 꺼지면
지역과 **마커까지** 사라진다(전체 지도의 `data-site` · 확대 지도의
`data-core`). 숫자가 안 따라오면 감춘 것이 보이는 것과 같은 수를 말한다.

### 감추는 것은 클래스다 — `[hidden]` 이 아니다

`.maptree .mslide` 가 `display: flex` 라 `[hidden]` 은 진다(063). `.mhid` 를
`.maptree .mslide.mhid` 로 잡아 특이도로 이긴다. 브라우저 시험이
`getComputedStyle` 로 확인한다.

### 로스해 확대 ↔ 나무는 CSS 하나로 잇는다

`views._map_ctx` 가 지점·지역에 `ross_out` 을 적는다 — 판정은 확대 지도가
마커를 거르는 그 함수(`ross.in_frame`) 하나라, 마커가 있는 지점은 나무에도
있고 없는 것은 없다. 화면에서는 `.mapstage.zoomRoss ~ .maplegend .outross`
가 감춘다 — `.mapstage` 와 `.maplegend` 가 `.mapwrap` 안의 형제라 `~` 로
닿고, 확대 전환 스크립트(199)를 한 글자도 안 고쳤다. 고르기 판의 지역·코어도
같은 클래스로 함께 빠진다.
