# 로스해만 따로 확대해 본다 (EPSG:3031 · 180° 돌림 · 지점 마커)

**작성일** 2026-09-17 · 사용자 요청 "시료 채취 위치를 지도에서 보는 기능에 더해서,
로스해 영역만 더 자세하게 보는 기능"

---

## 왜 필요한가 — 전체 지도에서는 한 점이다

남극 지도(021)는 9,200 km 를 900 px 에 담는다. 시료는 로스해에 몰려 있다 —
KPDC 에서 긁어 온 좌표(197)로 보면 지점 여섯이 300 km 안, 그 가운데 RS21 의
GC03B·GC04·GC05 는 **50 km 안**이다. 전체 지도에서 50 km 는 5 px 이라 셋이
마커 하나로 겹친다.

그리고 **더 나쁜 것이 하나 있었다.** 197 이 좌표를 채운 자리는 `Locality`(지점)
인데 지도가 보는 것은 `Site.lat/lon`(지역)이었다. 지역 칸은 그대로 비어 있어서
RS14·RS19·RS21·RS23 네 지역이 **전부 "대략 위치" 한 점(−75°, 175°)에 겹쳐
찍히고 주황 오차 원까지 달고 있었다** — DB 에는 실측 좌표가 있는데.

## 결정한 것

### 지역 좌표가 비면 지점 좌표의 평균으로 — 대략값이 아니다

`data.map_points()` 의 좌표 고르기가 셋이 됐다: 지역 좌표 → **관찰이 있는
지점 좌표의 평균** → 해역 대략값. 지점 좌표는 실측이므로 그 평균도 `exact`
다 — 오차 원을 안 그린다. 지점끼리 수백 km 갈리는 지역이면 그 흩어짐 자체가
지도에서 보일 것이고, 그것을 가르는 것이 확대 지도의 일이다.

`Site.lat/lon` 을 자동으로 채우지는 않는다 — 지역 좌표는 사람이 확정하는
칸이라는 `Site` 머리말의 규칙 그대로다. 지도가 읽을 때만 물러난다.

### 확대 틀은 같은 투영을 180° 돌린 것이다

새 투영을 들이지 않았다. EPSG:3031 을 그대로 쓰되 좌표를 (x, y) → (−x, −y)
로 뒤집었다 — 중앙자오선 180° 의 극구면투영과 같다. 왜 돌리는가: 전체 지도는
0° 가 위라 로스해(180° 언저리)에서는 **남극점이 위, 북쪽이 아래**로 온다.
빙붕이 위에 있고 빅토리아랜드가 오른쪽인 로스해 지도는 아무도 그렇게 안 본다.

같은 투영이라 얻는 것이 둘이다.

- 마커는 `_polar_xy` 값을 `ross.to_xy` 로 뒤집기만 한다 — 식이 하나다
- **전체 지도 위에 틀을 사각형으로 그릴 수 있다** (`ross.FRAME` · 돌리기 전
  좌표). 어디를 확대하는지 보이고, 누르면 확대로 간다

틀은 x −850..650 · y 950..2150 (km, 전체 지도 좌표) — 케이프 어데어(71°S)부터
로스 빙붕 앞면 남쪽 300 km 까지, 서쪽으로 케이프 콜벡. RS19-GC17(67.6°S,
관찰 0)은 틀 밖이다. **틀 밖의 지점은 안 찍고 이름으로 낸다** ("로스해 틀 밖:
AM22-GC10B · WAP13-GC47") — 잘려서 안 보이는 것과 없는 것은 달라야 한다.

### 해안선은 1:10m 을 틀에 잘라 다시 굽는다

50m 자료를 10 km 로 단순화한 전체 지도는 이 틀에서 정점이 6 px 마다 하나라
각진다. `tools/build_map_ross.py` 가 Natural Earth 1:10m 을 **서덜랜드-호지먼으로
틀에 자른 뒤** 1.5 km(≈ 1 px)로 단순화한다. 남극 대륙 고리 하나가 정점
수만 개라 자르지 않고는 단순화해도 무겁다. 결과는 32 KB — 전체 지도(10 KB)와
함께 늘 내려보낸다. 따로 요청하면 갈아타는 것이 즉시 안 된다(021 과 같은 판단).

**빙붕을 따로 얹는다.** NE 의 `land` 는 남극에서 빙붕 앞면을 해안선으로 삼아
로스 빙붕까지 육지다. 시료가 앉는 바다와 빙붕의 경계가 곧 빙붕 앞면이고, 그
안쪽이 접지된 땅인지 떠 있는 얼음인지는 시추 자료를 읽을 때 뜻이 있다.
`ne_10m_antarctic_ice_shelves_polys` 를 빗금으로 얹었다 — 지도의 관례다.

### 밟은 것 — 빙붕 한가운데 세로선

처음 그렸을 때 **180° 자오선을 따라 빙붕을 가르는 세로선**이 났다. NE 자료가
다각형을 180° 에서 갈라 놓아, 면에 획을 두르면 그 이음매가 선으로 나온다 —
시료가 앉는 바로 그 자리다. 자른 사각형의 가장자리도 같은 종류의 가짜 변이다.

면과 선을 갈랐다. 면(`LAND`·`SHELF`)은 획 없이 채우고, 선(`*_LINE`)은 이음매에
놓인 변을 뺀 열린 polyline 으로 따로 긋는다. 자료가 두 벌이라 크기가 두 배
가까이 되지만(16 → 32 KB) 선을 없애는 다른 길이 없었다 — 다각형을 합치는
것은 지오 라이브러리 없이는 할 일이 아니다.

**단위를 한 번 틀렸다.** 선을 만드는 자리에 km 로 바꾼 좌표를 넣고 나서 다시
1000 으로 나눴다 — 선 좌표가 전부 −2..1 이었다. 시험(`_path_ok` + 좌표 범위)이
그것을 잡는 자리가 됐다: **속성에 값이 있는 것과 값이 유효한 것은 다르다**(021).

### 마커는 지역이 아니라 지점이고, 이름표 자리는 서버가 고른다

이 틀을 여는 이유가 같은 지역의 코어들을 가르는 것이라 마커가 지점이다.
이름표는 `RS21-GC02` — `Locality.__str__` 과 같다.

전체 지도처럼 전부 마커 위에 얹으면 RS21 셋의 글자가 서로 덮는다. 브라우저에서
겹침을 풀 수도 있지만 **서버가 자리를 고르면 시험이 볼 수 있다.**
`ross.place_labels()` 가 위 → 오른쪽 → 왼쪽 → 아래 → 네 귀퉁이 순으로 놓아
보고 먼저 놓인 것과 안 겹치는 첫 자리를 준다. 글자 폭은 `0.6 × 글자 크기 ×
글자 수` 로 어림한다 — 브라우저 글꼴을 서버가 모르니 정확할 수 없고, 겹침
판정에는 그만하면 된다.

**밟은 것 — `text-anchor` 속성이 CSS 에 진다.** 자리를 골라 `text-anchor="start"`
를 줬는데 전부 가운데로 찍혔다. `.antmap .site .tag { text-anchor: middle }`
이 있어서다 — CSS 가 표현 속성을 이긴다. 클래스(`a-start`·`a-end`)로 옮겼다.
"감추는 CSS 는 `base.html` 이 그 요소를 어떤 선택자로 잡는지 보고 쓴다"(051)의
같은 줄이다 — 이번엔 감추는 것이 아니라 정렬이었다.

### 전환은 화면에서, 기억은 `localStorage` 로

`.mapstage` 가 두 SVG 를 품고 `zoomRoss` 클래스로 갈아탄다. 표·카드·지도
전환(020)과 같은 모양이고 키는 `diaruga.mapzoom`. `[hidden]` 은 `.antmap` 의
display 에 지므로(063) 클래스로 감춘다. 전체 지도의 틀 사각형과 "로스해" 글자를
눌러도 확대로 간다.

## 버린 것

- **한 SVG 의 viewBox 만 바꾸는 확대.** 자료가 50m 라 각진다. 1:10m 을 통째로
  넣으면 대륙 전체가 수백 KB 다
- **지도 타일·지오 라이브러리.** 021 의 판단 그대로 — 사내망 TLS 가 딸려 온다
- **`Site.lat/lon` 자동 채우기.** 사람이 확정하는 칸이다. 지도가 읽을 때만
  물러나는 것으로 충분하고, 지역 편집 화면이 이 값을 보여 주는 것은 아니라
  "자동값이 사람 것을 덮는" 갈래도 없다
- **이름표를 코어 코드만으로.** `GC04` 가 RS14 와 RS21 에 둘 있다 — 지역을
  떼면 같은 지도에서 같은 이름이 둘이 된다

## 다시 굽는 법

```bash
cd tools
curl -sSL -o ne_10m_land.geojson \
  https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_land.geojson
curl -sSL -o ne_10m_antarctic_ice_shelves_polys.geojson \
  https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_antarctic_ice_shelves_polys.geojson
python3 build_map_ross.py coast ne_10m_land.geojson ne_10m_antarctic_ice_shelves_polys.geojson 1500
```

나온 네 상수를 `web/viewer/ross.py` 의 같은 이름에 붙여 넣는다(수심대는
`bathy` 모드 — 200 에 있다). 틀을 옮기면
**도구의 `FRAME` 과 `ross.FRAME` 을 함께** 고친다 — 도구는 그 값으로 자르고
뷰어는 그 값으로 사각형을 그린다.
